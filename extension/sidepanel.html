    Hands

    This table is our best guess of how many resource cards each player has (wood, brick, sheep, wheat, ore). We build it by reading the same game messages you see in the activity feed, not by peeking inside hidden hands.

    Unknown means “some cards, but we don’t know which type.” That usually happens when the game only shows a face-down card — for example, someone steals from another player and the card type stays secret. A positive number is a guess that someone gained that many mystery cards; a negative number is a guess that someone lost that many.

    Rows with a warm stripe on the left are ones where Unknown is not zero (above zero or below zero). That is a heads-up: something hidden happened, so the typed columns for that player may be less certain until we learn more.

    Below the table, the list shows recent feed lines and resource changes we applied from them.
